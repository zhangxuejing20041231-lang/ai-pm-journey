# 开源大模型学习清单

这份清单收的是现在主流的开源（开放权重）大模型，就是可以公开下载模型文件、自己部署和研究的那一类，和只能在线用的闭源模型相对。每条写了发布方、大致的参数规模、最大的特点，以及现阶段适合拿它学什么。

看的时候抓住几个反复出现的词就行：参数规模决定模型“脑容量”的大致量级；MoE（混合专家）的意思是模型内部有很多个“专家”模块，每次回答只调用其中几个，所以总参数很大、实际计算量没那么大；上下文长度是它一次能读进去多少字。链接都在 2026-11-26 核对过，指向 Hugging Face 上的官方页面。

## 国内厂商

### 1. Qwen3（阿里巴巴，通义千问）

- 参数规模：一整个家族，稠密模型从 0.6B 到 32B，MoE 模型有 30B（激活 3B）、235B（激活 22B）等
- 最大的特点：中文能力强、尺寸最全，从手机能跑的小模型到旗舰都有，Apache 2.0 协议，用起来限制少
- 适合学什么：最适合做第一次本地体验。挑 0.6B 或 1.7B 这种小号，用 Ollama 之类的工具在自己电脑上跑起来，直观感受“下载一个模型文件就能离线对话”是怎么回事；再对比一下大号和小号的回答质量，理解参数规模意味着什么

链接（以最小号 0.6B 的页面为例，页面里有整个系列的说明）：https://huggingface.co/Qwen/Qwen3-0.6B-Base

### 2. DeepSeek-V3（深度求索）

- 参数规模：总参数 671B，每个 token 只激活 37B，MoE 架构
- 最大的特点：用远低于同行的训练成本做出了接近顶级闭源模型的水平，2024 年底发布时在行业里震动很大；它用的 MLA（多头潜在注意力）和自研 MoE 结构是常被讨论的技术点
- 适合学什么：理解 MoE 的最佳案例——“总参数 671B、激活 37B”这组数字到底是什么意思，为什么这样能省算力。模型本体太大，自己电脑跑不了，看它的模型介绍页和技术报告摘要就够了

链接：https://huggingface.co/deepseek-ai/DeepSeek-V3

### 3. DeepSeek-R1（深度求索）

- 参数规模：本体 671B（激活 37B）；另外有蒸馏版小模型，从 1.5B 到 70B
- 最大的特点：专门强化“推理”的模型，回答前会先写一长串思考过程再给出答案，是 2025 年初让“慢思考”出圈的开源代表作
- 适合学什么：理解“推理模型”和普通聊天模型的区别：为什么想得久一点、答案会更准，代价又是什么（更慢、更费 token）。想亲手体验可以跑它的蒸馏版小号，比如 1.5B、7B

链接：https://huggingface.co/deepseek-ai/DeepSeek-R1

### 4. Kimi K2（月之暗面 Moonshot AI）

- 参数规模：总参数约 1T（1 万亿），每个 token 激活 32B，MoE 架构；新版上下文 256K
- 最大的特点：主打 Agent 能力，就是能自己调用工具、写代码、把多步骤任务干完，在编程类评测里表现靠前
- 适合学什么：等学到 Agent 那一课时回来对着看：为什么这类模型要专门练工具调用，参数表里的“专家数量 384”是什么意思。它只能通过 API 或云端体验，本地跑不动

链接：https://huggingface.co/moonshotai/Kimi-K2-Instruct

### 5. GLM-4.6（智谱 Z.ai）

- 参数规模：旗舰级 MoE 模型，上下文 200K
- 最大的特点：国产模型里主打编程和 Agent 任务的一款，口碑集中在“写代码好用、性价比高”，权重开放、可商用
- 适合学什么：和 Kimi K2、DeepSeek 放在一起对比着看，能看清国内几家做大模型的路线差异：同样做 MoE，各自押注的方向不一样

链接：https://huggingface.co/zai-org/GLM-4.6

## 国外厂商

### 6. Llama 3.3（Meta）

- 参数规模：主力是 70B 稠密模型，上下文 128K
- 最大的特点：开源生态的“地基”之一，基于它改出来的模型和教程数量最多，遇到问题最容易搜到现成答案。注意它的许可证是 Meta 自己的社区许可证，不是完全无限制的开源协议
- 适合学什么：理解开源生态是怎么围绕一个基础模型长起来的；以后真要动手做小实验，优先选它，配套资料最全

链接：https://huggingface.co/meta-llama/Llama-3.3-70B-Instruct

### 7. Gemma 3（Google）

- 参数规模：1B、4B、12B、27B 四档，上下文 128K
- 最大的特点：轻量、多模态（能同时看文字和图片），出自做 Gemini 的同一个团队，主打“小而能干”、能在普通设备上跑
- 适合学什么：学“多模态”这个概念时的首选案例。4B 版本量化后普通电脑能跑，可以拿它试“发一张图片让模型描述”的效果

链接：https://huggingface.co/google/gemma-3-27b-it

### 8. Mistral Small 3.1（Mistral AI，法国）

- 参数规模：24B，上下文 128K，Apache 2.0 协议
- 最大的特点：欧洲厂商的代表作，走“中等体型、性能密度高”的路线，带视觉理解能力；官方说量化后一张 RTX 4090 或者 32GB 内存的 Mac 就能跑
- 适合学什么：理解“不是越大越好”——产品选型时为什么很多场景宁可用一个跑得快、成本低的中号模型。也是观察非中美厂商怎么做模型的样本

链接：https://huggingface.co/mistralai/Mistral-Small-3.1-24B-Instruct-2503

### 9. gpt-oss（OpenAI）

- 参数规模：两个型号，120b 是总参数 117B、每个 token 激活 5.1B；20b 是总参数 21B、激活 3.6B，都是 MoE，Apache 2.0 协议
- 最大的特点：OpenAI 自 GPT-2 之后第一次开放权重，本身就是个行业信号；20b 只要 16GB 内存就能跑，推理和工具调用能力按官方说法接近自家小型闭源模型
- 适合学什么：一是看头部闭源厂商为什么开始开放权重（生态和开发者心智的考虑，是很好的产品分析素材）；二是 20b 适合在配置不错的电脑上本地跑，体验“会思考、会用工具”的模型

链接：https://huggingface.co/openai/gpt-oss-120b

## 现阶段怎么用这份清单

先不用下载任何东西。把每条的“参数规模”和“特点”读一遍，在脑子里建一张地图：哪几家是国内的、哪几家是国外的，谁走大 MoE 路线、谁走小而精路线。等学到“什么是大模型”和 Token 那几课，再挑 Qwen3 的小号亲手在电脑上跑一次，这张地图就活了。
