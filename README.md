# AI PM Journey

我的目标是成为 AI 产品经理或 FDE（Forward Deployed Engineer）。
这个仓库用来记录我从入门开始的学习过程：学到的概念、拆过的产品、做过的小实验。
写下来一方面是给自己复盘，另一方面也方便以后回头看，我到底是怎么一步步学会的。

## 内容安排

| 文件夹 | 内容 | 节奏 |
| --- | --- | --- |
| `notes/` | 学习笔记：一个概念，尽量用自己的话说清楚，再记一下还没弄懂的地方 | 每天一篇 |
| `product-teardowns/` | AI 产品拆解：用户是谁、解决什么问题、体验怎么样、靠什么赚钱 | 每周一篇 |

## 我对这两个岗位的理解

AI 产品经理更多是在定义问题：用户遇到了什么麻烦，值不值得用 AI 来解，
做成什么样，之后怎么判断做得好不好。

FDE 离客户更近，要到真实业务里去理解问题，然后自己动手把方案搭出来，
让它真的能用，再根据现场的反馈继续改。

两者都要懂 AI 能做什么、做不到什么，也都要会沟通、会快速验证想法。
这是我接下来一段时间主要练的能力。

## 路线

1. 先把 GitHub、Git 和 AI 的基本概念弄明白，保持记录的习惯
2. 每周拆一个 AI 产品，慢慢培养产品感觉
3. 开始做 Prompt、Agent 和 API 的小实验，做出能演示的东西
4. 把做过的东西整理成完整案例：问题、方案、原型、评估、复盘
