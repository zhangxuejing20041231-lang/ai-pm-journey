## 🧭 我的理解：AI PM 和 FDE 是什么？

- **AI 产品经理**：站在用户和业务这边，定义“要解决什么问题”，
  设计产品方案，和工程师一起把它做出来，再用数据和评估看它到底好不好用。
- **FDE（前线部署工程师）**：更靠近客户现场，快速理解真实业务问题，
  亲手用代码和 AI 能力搭出可用的方案，部署、迭代，再把现场经验反馈给产品团队。
- **共同点**：都要懂 AI 的能力与边界、会快速做原型、会沟通、会评估效果。
  这正是我要在这里练的四件事。

## 🎯 路线图

- **阶段一**：GitHub + AI 基础概念，每日记录不断更
- **阶段二**：每周 1 次 AI 产品拆解
- **阶段三**：Prompt / Agent 实验 + API 入门，做出能演示的小 Demo
- **阶段四**：完整的作品集案例（FDE 风格：问题 → 方案 → 原型 → 评估 → 复盘）
